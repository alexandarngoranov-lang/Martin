# Martin Goranov — Portfolio

Site statique prêt pour GitHub Pages.

## Publication
1. Créer un dépôt GitHub.
2. Importer tout le contenu de ce dossier à la racine du dépôt.
3. Ouvrir **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Choisir **main** et **/(root)**, puis **Save**.

Le site fonctionne sans build : `index.html`, `styles.css`, `script.js` et `assets/`.
